ⓘ Methodology

Win rate uses only closed positions with known realized P&L. Flat trades are shown separately. Historical rows without a final P&L are not counted as losses.

✓ Anonymous aggregate data

The analytics dataset stores a one-way anonymous user hash. Raw user IDs, wallet addresses and emails are not stored in this analytics database. OpenAI is not used to calculate these statistics.
