MEMEFLOW TYPE SCALE V180

Exactly 8 text sizes:
11 / 12 / 13 / 14 / 15 / 17 / 24 / 36 px

V180 replaces V179 canonical; it does not add another style layer.
Old arbitrary text sizes and text clamp/calc rules are normalized into
the eight semantic sizes. Decorative icon/glyph geometry is excluded.

Install:
unzip -o Memflow-Type-Scale-V180.zip && bash memeflow_type_scale_v180/install.sh

Audit:
bash memeflow_type_scale_v180/audit.sh

Rollback:
bash memeflow_type_scale_v180/rollback.sh

No automatic server/system restart.
