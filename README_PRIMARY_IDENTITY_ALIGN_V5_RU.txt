MEMEFLOW Primary Identity Align V5

Цель:
- AI SCORE не двигается.
- Аватар по высоте подгоняется к видимым цифрам AI SCORE: верх к верху, низ к низу.
- Маленький символ (#primaryMeta) НЕ стоит справа от большого имени.
- Маленький символ стоит ПОД большим именем (#primaryName).
- Левые края большого имени и маленького символа совпадают по одной вертикальной линии.
- Под аватаром маленького символа больше нет.

Установка:
unzip -o MEMEFLOW_PRIMARY_IDENTITY_ALIGN_V5.zip
node install-primary-identity-align-v5.mjs
node verify-primary-identity-align-v5.mjs

После этого Stop -> Run и открыть сайт заново.
