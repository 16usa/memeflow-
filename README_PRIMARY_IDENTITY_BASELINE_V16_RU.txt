MEMEFLOW — Primary Identity Baseline V16

Что делает
-----------
- Возвращает маленькое название / symbol под большим названием.
- Выравнивает его по низу с подписью AI SCORE справа.
- AI SCORE и число не двигает.
- Логотип не создаёт и не трогает.

Установка
---------
unzip -o MEMEFLOW_PRIMARY_IDENTITY_BASELINE_V16.zip
node install-primary-identity-baseline-v16.mjs
node verify-primary-identity-baseline-v16.mjs
