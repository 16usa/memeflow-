MEMEFLOW SYSTEM OVERVIEW AGENT PERFORMANCE V1

Adds Agent Performance as slide 06 / 06 in the existing System Overview carousel.
It uses the existing live iframe preview system, has an SVG fallback, and opens /agent-performance.html.

Install:
unzip -o MEMEFLOW_SYSTEM_OVERVIEW_AGENT_PERFORMANCE_V1.zip && node MEMEFLOW_SYSTEM_OVERVIEW_AGENT_PERFORMANCE_V1/install.mjs

Rollback:
node MEMEFLOW_SYSTEM_OVERVIEW_AGENT_PERFORMANCE_V1/rollback.mjs
