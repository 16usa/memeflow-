MEMEFLOW AI CENTER STAR V21

FIXES FROM V20
--------------
- The AI star is now exactly in the center of the bottom navigation row.
- It no longer creates a second/lower row.
- ALL visible button chrome is removed.
- No border.
- No rounded box.
- No background.
- No shadow around a button.
- Visually, only the ✦ star is visible.
- A transparent 48x48 hit area remains for reliable tapping.
- Wallet stays in the top-right header as an icon.
- V20 direct evaluator config is preserved unchanged.

INSTALL
-------
cd ~/workspace
unzip -o MEMEFLOW_AI_CENTER_STAR_V21.zip
node MEMEFLOW_AI_CENTER_STAR_V21/apply-ai-star-v21.mjs

Then:
Stop -> Run -> refresh Safari.

ROLLBACK
--------
cd ~/workspace
node MEMEFLOW_AI_CENTER_STAR_V21/rollback-ai-star-v21.mjs
