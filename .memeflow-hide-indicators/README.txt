MEMEFLOW Hide Chart Indicators

Purpose:
- Hides the chart indicator selector row under the chart:
  MA, EMA, BOLL, SAR, VOL, MACD, KDJ, RSI, StochRSI, TRIX, OBV, WR
- Leaves the chart and metrics intact.
- Does not auto-restart the server.
- Creates a backup and pushes the change to git.

Install in Replit:
rm -rf .memeflow-hide-indicators && mkdir -p .memeflow-hide-indicators && unzip -o MEMEFLOW-Hide-Chart-Indicators.zip -d .memeflow-hide-indicators && bash .memeflow-hide-indicators/install.sh
