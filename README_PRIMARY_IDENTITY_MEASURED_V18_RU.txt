MEMEFLOW — Primary Identity Measured V18

Что делает
-----------
- Не наугад. Патч измеряет фактическую высоту #primaryScore в рантайме.
- По этой фактической высоте задаёт размер аватарки токена.
- Поэтому верх и низ аватарки совпадают с верхом и низом большого числа.
- Большое название токена ставится в первую строку вместе с числом.
- Маленькое название / symbol ставится во вторую строку вместе с подписью AI SCORE.

Установка
---------
unzip -o MEMEFLOW_PRIMARY_IDENTITY_MEASURED_V18.zip
node install-primary-identity-measured-v18.mjs
node verify-primary-identity-measured-v18.mjs
