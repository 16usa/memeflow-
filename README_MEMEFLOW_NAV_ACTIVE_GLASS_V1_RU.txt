MEMEFLOW — NAV ACTIVE GLASS V1

Что меняет
----------
ТОЛЬКО визуальное отображение активного пункта нижнего меню.

Обычная активная вкладка:
- старая яркая cyan-полоска слева убирается;
- появляется спокойная premium glass / matte плашка;
- текст становится белым;
- тонкий полупрозрачный cyan-контур;
- короткая cyan-линия 22 px снизу показывает выбранную вкладку;
- лёгкое внутреннее свечение;
- плавная анимация ~170 ms.

Центральная AI-кнопка:
- без прямоугольной плашки;
- при активном состоянии получает мягкое cyan-свечение;
- существующая иконка/звёзды не заменяются.

Что НЕ меняется
---------------
- порядок кнопок;
- ширина меню;
- размеры колонок;
- навигационная логика;
- data-sheet;
- обработчики click;
- страницы;
- торговая логика.

Установка
---------
unzip -o MEMEFLOW_NAV_ACTIVE_GLASS_V1_REVERSIBLE.zip
node install-memeflow-nav-active-glass-v1.mjs
node verify-memeflow-nav-active-glass-v1.mjs

Откат
-----
node rollback-memeflow-nav-active-glass-v1.mjs
