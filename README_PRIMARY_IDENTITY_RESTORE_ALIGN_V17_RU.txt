MEMEFLOW — Primary Identity Restore + Align V17

Что делает
----------
1. Убирает неудачную раскладку V16.
2. Возвращает раскладку V15:
   [родной логотип] [большое название]
                    [маленький symbol]
                                      [AI SCORE справа]
3. Маленький symbol остаётся под большим названием.
4. Только маленький symbol опускается/поднимается так, чтобы его низ совпал
   с низом подписи AI SCORE.
5. Логотип, большое название, число и AI SCORE не двигаются.

Установка
---------
unzip -o MEMEFLOW_PRIMARY_IDENTITY_RESTORE_ALIGN_V17.zip
node install-primary-identity-restore-align-v17.mjs
node verify-primary-identity-restore-align-v17.mjs
