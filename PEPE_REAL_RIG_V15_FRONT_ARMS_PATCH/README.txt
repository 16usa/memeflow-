PEPE REAL RIG V15 — FRONT ARMS PATCH

WHAT IT DOES
- Keeps V14 untouched.
- Creates a new V15 rig/test page.
- Forces left/right arms to render in front of the torso.
- Uses elbow / forearm / hand joints automatically when those joints exist.
- Keeps wrists upright.
- Does NOT touch the game page, rocket, market logic, START, or server logic.

INSTALL IN REPLIT SHELL
1) Upload this ZIP to ~/workspace.
2) Run:
   unzip -o PEPE_REAL_RIG_V15_FRONT_ARMS_PATCH.zip
   node PEPE_REAL_RIG_V15_FRONT_ARMS_PATCH/apply-pepe-rig-v15.mjs

3) Open:
   /character-real-test-v15.html?refresh=1501

ROLLBACK
node PEPE_REAL_RIG_V15_FRONT_ARMS_PATCH/rollback-pepe-rig-v15.mjs
