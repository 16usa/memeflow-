MEMEFLOW INTER ONLY V199

Purpose
- Use Inter as the single active font family everywhere.
- Do not change sizes, weights, colors, spacing, cards, geometry, or behavior.
- Remove active Inter Tight / IBM Plex Mono Google font loaders.
- Load one tiny family-owner stylesheet last on every top-level HTML page.

Important
- Existing page design stays intact.
- Technical values are Inter too.
- Prices are Inter.
- Mint/address/timestamps are Inter.
- Buttons/labels/headings/body are Inter.
- Only the family changes.

Install
  unzip -o Memflow-Inter-Only-V199.zip
  bash memeflow_inter_only_v199/install.sh

Rollback
  bash memeflow_inter_only_v199/rollback.sh
