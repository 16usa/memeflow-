PUMPSWAP MUST BECOME A VALID LIVE MARKET SOURCE

After migration, the token must NOT depend on stale Pump.fun market data.

Expected behavior:

Pump.fun bonding curve active
    -> use Pump.fun live market data

Migration occurs
    -> detect migration
    -> identify PumpSwap pool
    -> switch live market-data source to PumpSwap
    -> continue tracking the SAME token mint
    -> continue updating price/liquidity/volume/trades
    -> continue scoring/admission
    -> continue displaying the token

Do NOT create a duplicate token just because the market source changes.

The token identity remains the same mint.

IMPORTANT:

It should switch to the PumpSwap source if migration is confirmed.

PERSISTENCE:
