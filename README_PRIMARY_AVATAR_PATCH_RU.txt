MEMEFLOW — Primary Candidate avatar = одна линия с AI Score

Что изменено
------------
Этот патч делает 2 вещи в блоке PRIMARY CANDIDATE:
1. Подгоняет высоту аватара токена под высоту большого числа AI SCORE.
2. Выравнивает аватар по верхней линии числа AI SCORE.

Из-за этого верх и низ аватара становятся примерно на одной линии с числом.
Главное — именно визуальное выравнивание по высоте.

Установка в Replit
------------------
1. Загрузите ZIP в корень проекта.
2. Распакуйте ZIP.
3. В Shell выполните:

   node apply-primary-avatar-score-height.mjs

4. Перезапустите приложение и обновите страницу.

Откат
-----
   node remove-primary-avatar-score-height.mjs
