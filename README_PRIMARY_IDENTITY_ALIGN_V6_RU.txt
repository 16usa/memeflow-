MEMEFLOW Primary Identity Align V6

Что исправляет
--------------
1. Убирает старое плавающее / уезжающее позиционирование аватара.
2. Не двигает AI SCORE.
3. Собирает левую часть карточки структурно: [аватар] + [большое имя над маленьким].
4. Маленькое имя стоит ПОД большим именем и больше не висит под аватаром.
5. Размер аватара привязывается к высоте цифр AI SCORE без transform-сдвигов.

Установка
---------
unzip -o MEMEFLOW_PRIMARY_IDENTITY_ALIGN_V6.zip
node install-primary-identity-align-v6.mjs
node verify-primary-identity-align-v6.mjs

Потом Stop -> Run и обновить страницу.
