MEMEFLOW Premium Mobile V1.3 — Header Edge

Что делает
----------
- Верхняя шапка растягивается от левого края viewport до правого края viewport.
- Скругление 14px, как у нижнего мобильного меню.
- PAPER MODE, FREE PLAN и иконка кошелька стоят в одной горизонтальной строке.
- У кнопки кошелька полностью убраны рамка, фон и квадратная плитка — остаётся только иконка.
- Wallet offline / RPC online остаются второй строкой внутри той же шапки.
- Остальной Premium Mobile V1 не меняется.

Установка
---------
unzip -o MEMEFLOW_PREMIUM_MOBILE_V1_3_HEADER_EDGE.zip
node install-memeflow-premium-mobile-v1-3-header-edge.mjs
node verify-memeflow-premium-mobile-v1-3-header-edge.mjs

Откат только V1.3
-----------------
node rollback-memeflow-premium-mobile-v1-3-header-edge.mjs
